    Modernist study / original HTML and CSS

    A / a useful route

    Reference: Edward McKnight Kauffer, drawing (1934), V&A E.3770-2004. The coach inspected the actual linked image: segmented black figure, repeated bars/circular joints, spiral hand and a diagonal pale plane. V&A source.

    Aligned modules organize image, words and controls; a diagonal pale field suggests movement without copying the figure. One sans-serif family and repeated rules create a direct reading order. The system uses the same palette as B.

    Intended effect: Help someone quickly picture a put-together everyday outfit. Risk: The regular structure may feel like another generic basics shop.

    Audience effect is a hypothesis, not research. The product, price, headline, support and action match the other study. Compare both.
